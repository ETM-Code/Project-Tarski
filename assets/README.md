# Assets

This directory stores project collateral and exports: presentations, screenshots, report graphics, and other non-source artifacts.

## Layout

- `documents/`: project documents and slide exports
- `images/`: still images used in demos and reporting
- `videos/`: exported demo videos
- `research-papers/`: external reading material
- `technical-notes/`: notes, calculations, and supporting exports
- `demo-assets/`: demo-facing logos and media
- `flow-charts/`: draw.io sources and chart exports

## Guidance

- Treat this folder as outputs and references, not canonical implementation source.
- Keep reproducible source files in their owning project directories and only place generated assets here.
