# Assets

This directory is a holding area for project collateral: exported PDFs, presentations, screenshots, figures, and working documents accumulated across the Tarski project.

It is intentionally retained for reference, but it is not the main source tree for code or reproducible tooling.

## What Lives Here

- Presentations and pitch materials
- Exported planning and report documents
- Rendered board images and poster assets
- Supporting papers and background references
- The `synapse-neuron-9x-report/` validation mini-project

## Guidance

- Prefer linking to reproducible sources elsewhere in the repo when they exist.
- Treat screenshots and office exports here as outputs, not canonical source.
- Add new long-lived documentation to a dedicated project folder when possible rather than expanding this directory further.
