# Laptop GUI Prototype

This directory contains a separate GUI prototype for interacting with Tarski hardware/software components.

## Layout

- `src/`: frontend source
- `main.py`, `tarski_board.py`, `tarski_tui.py`: Python entrypoints and support code
- `docs/`: project notes for this prototype

## Status

This is a side project/prototype area rather than the main emulator UI. Treat generated frontend output, local Python environments, and installed packages here as disposable.
