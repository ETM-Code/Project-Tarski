# Laptop GUI Prototype

Prototype desktop/UI work for interacting with Tarski hardware and tooling.

## Layout

- `src/`: frontend source
- `main.py`, `tarski_board.py`, `tarski_tui.py`: Python entry points and support code
- `docs/`: notes specific to this prototype

## Status

This is a side prototype, not the primary emulator UI. Prefer `Tarski-Emulator` for active interface development.
